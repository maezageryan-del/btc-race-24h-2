A dip-buy mean-reversion bot that trades cbBTC/USDC on one-minute bars: it stays in cash and only buys a dip of more than 1.6% below the 6-hour high once the close has started to turn back up, then protects the trade with a 2% take-profit, a 1% hard stop on cost, a 0.8% trailing stop and a stall exit.

## Run it

```sh
node main.ts
```
